README

Board-like is a competitive 2-4 player single-device game with rogue-like elements developped in Godot.


The game consists of a set amount of short 1-3 minute rounds(5-20). Players earn, sacrifice and sell their levels using different power-ups, tiles and cards. The player with the highest level at the end of the game wins!

The RNG allows for unique situations no matter how many times you play

QUICK TUTORIAL

Use mouse for controls, ESC to pause.

Start the game by clicking on the "START" button in the main menu, choosing the right game settings and setting up player profiles.
